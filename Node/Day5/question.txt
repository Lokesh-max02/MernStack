4.what is middleware

*Middleware is a function on express.js that execute between in request and response cycle.It is access to the request and response and next function().

*It is used for authentication ,logging,validation and error handling.

Why do we use Middleware?
Middleware is used for:
1. Authentication – Checks whether the user is logged in.
2. Logging – Records client request information.
3. Validation – Checks whether the incoming data is valid.
4. Error Handling – Handles errors in the application.
5. Parsing JSON – Reads JSON data from client requests.

5.what is cors

CORS-stand for cross origin resourse sharing .
*It is used for security mechanism that allows and restricts frontend application from accessing resources from different origin.
*In express.js we can enable CORS using cors package

Why do we use CORS?
1. To allow communication between frontend and backend.
2. To control which origins can access backend resources.
3. To handle cross-origin browser requests securely.
4. To prevent unauthorized websites from accessing resources through browsers.

7.what is json

*JSON stands for JavaScript Object Notation. It is a lightweight data interchange format used to exchange information between frontend and backend applications. It stores data in key-value pairs and supports strings, numbers, booleans, arrays, objects, and null.

Why Do We Use JSON?
1. To exchange data between frontend and backend.
2. To send user information through APIs.
3. To receive data from the server.
4. To store structured data.
5. It is easy to read and understand.

8.what is status code

HTTP Status Codes are three-digit numbers sent by the server to indicate the result of a client's request. They are divided into five categories: 100 series informational, 200 series success, 300 series redirection, 400 series client error, and 500 series server error.

11.what difference node and express

Node:
1.It is a runtime environment
2.Runs JavaScript outside the browser.
3.Used to create servers and backend applications.
4.Requires more code for routing.
5.Does not require Express to work

Express:
1.It is a web framework.
2.Runs on Node.js.
3.Makes backend development easier.
4.Provides simple routing methods.
5.Requires Node.js to work.
